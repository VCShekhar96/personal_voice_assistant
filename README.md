# 🎤 Voice_assistant

A Python-based intelligent voice assistant capable of recognizing speech, executing commands, and responding using natural language. Designed to automate daily tasks with hands-free interaction.

---

## ✨ Features
- Speech recognition and text-to-speech support  
- Task automation (open apps, search web, send emails, etc.)  
- Integration with APIs for weather, news, and AI responses  
- Wake word detection and custom command support  

---

## 🧠 Tech Stack
- **Python 3.10+**
- **SpeechRecognition, pyttsx3**
- **OpenAI / GPT API**
- **Flask (optional web mode)**

---
