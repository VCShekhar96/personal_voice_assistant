# 🎙️ Personal Voice Assistant

A smart **Python-based Voice Assistant** that listens to user commands, performs automated tasks, and responds using speech synthesis.  
It demonstrates **Natural Language Processing (NLP)**, **speech recognition**, and **voice automation** capabilities — similar to Siri, Alexa, or Google Assistant.

---

## 🧾 Overview

The **Personal Voice Assistant** is designed to make everyday tasks hands-free and efficient.  
It can search the web, open applications, tell the time or weather, send emails, and more — all through simple voice commands.  

This project showcases integration of **speech recognition**, **text-to-speech**, and **API-based automation** using Python.

---

## ✨ Features

- 🗣️ **Speech Recognition** – Understands voice input and processes user commands  
- 🔊 **Voice Response** – Converts text to natural-sounding speech  
- 🌐 **Web Search** – Opens Google, YouTube, or Wikipedia results instantly  
- 🕒 **Time & Date Query** – Announces the current time and date  
- 💌 **Email Automation** – Sends emails through voice command  
- 🧠 **Modular Commands** – Easily extendable for new features  

---

## 🧰 Tech Stack

- **Language:** Python  
- **Libraries Used:**
  - `speech_recognition`
  - `pyttsx3`
  - `datetime`
  - `webbrowser`
  - `os`
  - `smtplib` (for email)
  - `requests` (optional for APIs)
